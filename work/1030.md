## Task 1: Build & Render 3D Model

- `scripts/build_3d_model.py` samples `D:\SaveData\current\rts_X1.tif`, `rts_Y1.tif`, and `rts_Z1.tif`, filters points close to the camera origin, recentres the mesh around its bounding-box midpoint (use `--no-center` to disable), and writes `generated_surface.obj` to both `TestData/models/` and `D:\SaveData\current\`. With `open3d` installed you can export `generated_point_cloud.ply` and preview it with `--show`.
- Copy Qt's `balsam.exe` (e.g. `C:\Qt\6.10.0\llvm-mingw_64\bin\balsam.exe`) into `bin\`, then run:
  ```powershell
  python scripts/build_3d_model.py --step 4 --balsam .\bin\balsam.exe --show
  ```
  Balsam produces `Generated_surface.qml`/`defaultobject_mesh.mesh` in `D:\SaveData\current\`; the script mirrors the mesh and centering metadata back to `TestData/models/`.
- The UI now directly loads `file:///D:/SaveData/current/defaultobject_mesh.mesh`; after each capture completes, `Cores.CoreState.refreshDataSources()` reloads that mesh and View3D auto-centres it using the runtime bounds, so the model appears correctly positioned without relying on fallback assets.

> Only render the actual structured-light point cloud--no camera-origin vertex or artificial closing faces.
