## Task 1: Build & Render 3D Model

- `scripts/build_3d_model.py` now samples `D:\SaveData\current\rts_X1.tif`, `rts_Y1.tif`, and `rts_Z1.tif`, filters points close to the camera origin, and writes `generated_surface.obj` to both `TestData/models/` and `D:\SaveData\current\`. When `open3d` is installed you can also export `generated_point_cloud.ply` and preview it with `--show`.
- Copy Qt's `balsam.exe` (e.g. `C:\Qt\6.10.0\llvm-mingw_64\bin\balsam.exe`) into the repo `bin\` folder, then run:
  ```powershell
  python scripts/build_3d_model.py --step 4 --balsam .\bin\balsam.exe --show
  ```
  This produces `generated_surface.mesh` alongside the OBJ and keeps a backup under `TestData/models/`.
- The UI refreshes model paths via `Cores.CoreState.refreshDataSources()` after capture completes; it prefers `D:\SaveData\current\generated_surface.mesh` and falls back to the repository copy if loading fails, so the 3D panel stays functional.

> Only render the actual structured-light point cloud—no camera-origin vertex or artificial closing faces.
