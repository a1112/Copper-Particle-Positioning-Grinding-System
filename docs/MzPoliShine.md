# MzPoliShine 知识卡片

- 文件：`docs/MzPoliShine.km`（JSON 思维导图导出）
- 根节点：**MzPoliShine**
- 主要分支（可按需扩展）：
  - **状态/设备**：运行模式（待机/运行/暂停/报警/启动完成）、通讯状态、控制模式（自动/手动/教导）、IPC 负载等。
  - **记录与任务**：包含班次、批次、计划/实际开始结束时间、工件 ID、加工位置、参数摘要等。
  - **加工算法**：高度预测、工件平面高度、缺陷聚簇、X/Y/Z 运动范围、粒子类型等。

导图使用方式：从子节点的描述中读取数值或实际文件路径，再回写到 `configs/` 或数据库种子中。

- **设备与工艺**
  - 通过“磨削参数”节点读取直线速度/转速/进给方式/台面模式。
  - “工件”节点提供材料、尺寸、序列号等元信息，可直接粘贴到 `/config/meta`。
  - “控制模式”与“通信方式”节点可映射到 UI 的枚举标签。
- **加工算法**
  - “平面/高度”节点对应 `plane_height`，用于 UI 统计卡片。
  - “粒子/缺陷”节点提供 `blobs`、`clustered_ratio` 等默认参数。
  - “路径规划”节点记录 `mode`、`pixel_mm` 等 `/path/plan` 参数。

统计类与范围说明：

- `/config/meta` 中的 `nodes` 字段读取导图的层级文本。
- 预设的 X/Y/Z 范围用于模拟器判定运动轨迹是否越界。

在 UI 中：

- “状态概览”页展示运行模式、进给方式、台面模式、平面高度、冷却液等信息。
- 所有静态字段通过 `GET /config/meta` 加载；若导图中缺失，界面以 `-` 填充。

> 建议在维护工艺/知识库时同步更新 `.km` 与本文档，方便前后端对齐同一套术语。
